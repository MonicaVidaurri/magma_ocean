To make new stellar data files:

This model historically uses stellar tables by Baraffe et al. 2015
which can be found at: https://perso.ens-lyon.fr/isabelle.baraffe/BHAC15dir/

step 1. Go to tracks --> structure link

step 2. Find the *mass* closest to the star you're trying to use
    and copy the *time* and *L/Ls* columns. These will be your
    tbol/Lbol columns that this model reads in.

step 3. IMPORTANT: These are log values, so you will need to do
    10^[value] for each column value.

Save the file as tab-delimited text with a header row naming the two columns Lbol and tbol
(utils/stellar.py reads it; ages outside the table use the first or last value). Then point
the planet TOML at it:

    [star]
    stellar_track_file = "data/stellar_dataMyStar.txt"   # relative to the repo root

The track sets both the instellation (equilibrium temperature) and, through f_sat, the XUV
flux. The BHAC15 file also lists gyration radii (k2conv, k2rad); k2conv^2 + k2rad^2 is a good
value for star.tides.moi_factor.

If you wanna freestyle a stellar file using your own data and wanna compare with
the original GOOEY model but don't have the MATLAB license to do so, feel free
to email me (check out the README file) and I'll make it happen!
